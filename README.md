# A Multifactorial Analysis of Adjective Comoparison in Sri Lankan English

This repository includes our data (01a_adj.txt) and analysis (01b_adjSL.R) on which the paper "A Multifactorial Analysis of Adjective Comparison in Sri Lankan English" is based.  

Published in:
Funke, N. & K. Schmidt. 2026. "A multifactorial analysis of adjective comparison in Sri Lankan English." Grammar through the Lens of Corpus Linguistics, eds. J. Pérez-Guerra, Y. Fernández-Pena & A. E. Martínez-Insua. Amsterdam: John Benjamins. 43-65. https://doi.org/10.1075/scl.128.02fun

01a_adj.txt - data set on which the analysis is based  
01b_adjSL.R - random forest analysis of the choice between the analytic and synthetic adjective comparison  
01c_metadata.R - brief explanation of all variables included in 01a_adj.txt
